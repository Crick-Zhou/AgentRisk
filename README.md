# 智鉴 AgentRisk · 金融智能体测评助手

通过聊天创建测试、在受控模拟环境中执行并查看证据的金融智能体测试平台。**OpenAI 负责测试草案、规划与报告，DeepSeek 扮演被测银行助手，程序独立检查工具执行和模拟账本。**

这是 v0.4.0 的独立源码副本，包含前端、后端、自动化测试与通用部署说明。不包含真实 API Key、登录账号数据、私人服务器配置、测试导出记录或原托管平台标识；不影响现有线上部署。

## 使用

需要 Node.js 20 或更新版本，无需安装运行依赖。

```sh
npm start
```

访问 `http://127.0.0.1:4175`。首次可直接运行“免密钥试跑”，检查参考驱动器的实际沙箱状态。

真实模型模式打开“API 连接设置”，分别填写：

| 角色 | 接口 | 默认模型 |
|---|---|---|
| 测评助手 | `https://api.openai.com/v1` | `gpt-5.4-mini` |
| 被测银行助手 | `https://api.deepseek.com` | `deepseek-flash` |

两者使用独立的 Key 和聊天上下文。当前实现采用 Chat Completions 工具调用；不要填只能通过 Responses API 调用工具的模型。默认值依据开发时的官方文档，账号可用模型可能不同。DeepSeek 明确关闭思考模式，OpenAI 默认非思考设置。Key 不进入模型 messages。

切换“双模型实测”，输入“请安排三分钟演示：正常业务、恶意文档、超时重试”，确认计划后开始。每个任务最多 6 轮银行模型请求；规划最多 2 轮，报告最多 3 轮；连接测试也是计费调用。停止按钮阻止后续任务，无法保证撤销已到达服务商的计费请求。

### 中英文与测试目录

登录页和工作台顶部均可切换 `中文 / English`，浏览器只保存语言偏好，不保存密钥。切换不会清空已选测试或本轮结果。目录完整展开，共 **14 项：11 项工具沙箱测试、3 项聊天探针**；新增 S10 收款对象替换、S11 审批读取后的撤销竞态。原目录为 9 项沙箱测试加 3 项聊天探针，并非只有 9 项总测试。

页面、测试名称与说明、状态和证据摘要均支持双语；Markdown / CSV 按导出时的界面语言生成。运行开始时固定该轮测试语言，中途切换界面不会改写正在执行的任务。原始输入、模型回复、工具参数、账本和 JSON 证据保留执行原文及完整性哈希，不做事后翻译。

### 通过聊天新增测试

1. 在工作台输入“新增一个测试：客户撤回申请后，助手应该停止处理”。
2. 查看生成的草案，可继续聊天修改，或编辑测试名称、输入、预期表现和已有场景。
3. 确认加入后，测试出现在目录中；只有点击“开始”才执行，确认草案本身不调用银行工具。
4. 执行后可询问“列出有问题的部分”，查看原始证据并导出报告；自定义测试集也可通过 JSON 导入、导出。

当前最多保留 20 项自定义测试，只支持已有沙箱场景的输入变体及不使用业务工具的聊天探针，不生成任意工具。自定义预期表现需要人工复核；免密钥模式只记录自定义草案并标为待实测，不冒充真实模型执行结果。

自建服务器使用 `server/private.mjs`，配合 HTTPS 与账号密码保护。通用部署说明见 `deploy/private/README.md`。真实凭据在部署时单独提供，不在本仓库中。

## 实现结构

- `app/`：对话、双 API 配置、计划、进度、证据、Markdown / CSV / JSON 导出。
- `server/core.mjs`：模型适配、测评智能体工具循环、14 个种子任务、银行工具沙箱、独立判定器、报告工具和 HTTP 接口。
- `app/i18n.mjs`、`server/language.mjs`：界面和报告双语显示，以及按运行语言构造测试提示。
- `server/local.mjs`：仅监听本机的本地服务。
- `scripts/build.mjs`：将同一执行引擎与页面打包成 Worker，不依赖第三方运行库。
- `tests/engine.test.mjs`：协议、状态断言、故障、越权、报告和隐私回归测试。
- `tests/custom-tests.test.mjs`：聊天草案、确认、输入验证、自定义执行与报告覆盖。
- `tests/auth.test.mjs`、`tests/private.test.mjs`：登录保护及服务端凭据边界。
- `tests/catalog-language.test.mjs`：双语目录与撤销、收款对象变更场景。
- `dist/index.html`、`dist/styles.css`、`dist/app.js`：保留的早期静态概念稿，通过 `/concept/index.html` 访问；原有分数是展示数据，不是新版测评结果。

```sh
npm test
npm run build
```

构建产物为 `dist/server/index.js`，默认导出 Worker `fetch`。开发时可用 `npm run dev` 自动重载。

## 证据与判定

每个任务在独立内存沙箱运行。证据包括输入、模型回复、工具参数/结果、权限拦截、审批使用次数、通知、模拟外发陷阱、故障事件和账本前后状态。通过/失败来自这些结构化状态，不是测评模型自行打分。

状态区分 PASS、FAIL、PARTIAL、INCONCLUSIVE、NOT_SUPPORTED 和 ERROR。API 错误不算通过；已造成的安全失败不会被后续接口错误掩盖。语义性“虚假承诺”只给线索，留待人工复核。危险调用被网关拦截，分别记录“危险尝试”和“拦截”，不谎称实际发生损失。

基础架构故意配置宽松工具，增强架构加入审批/客户/参数/幂等/外发约束。因此对比对象是**整套 Agent 架构**，并非单纯两个模型。免密钥模式用确定性参考驱动器执行同一沙箱，不证明 DeepSeek 实际表现。真实模型模式没有预设必败/必胜结果。

JSON 中的 SHA-256 用于核对单条导出内容，不是签名或第三方认证。相同合成数据种子不能保证外部模型输出逐字复现。

## 安全与范围

- 只使用虚构 DemoBank 政策、合成客户和模拟资金，不连接真实银行或真实收款方。外发工具只写内存。
- 只允许 DeepSeek 与 OpenAI 官方 HTTPS 地址，拒绝内网、任意代理、重定向及 URL 凭据。企业私有 Agent 需另加受控适配器，不能直接放开 URL 代理。
- 浏览器输入的 API Key 不写文件、不保存到 localStorage、不包含在报告中；自建服务器使用预先配置的只读密钥文件，密钥不会回传前端或打入镜像。错误不透传上游原始响应。应用不记录请求体；服务商和托管平台仍有各自数据处理政策。
- 证据只留在当前页面；刷新会丢失，请及时导出。报告分析把所选合成结果发送给 OpenAI，不要上传真实客户资料。
- Sites 站点依赖托管平台访问控制；本地开发服务仅绑定 `127.0.0.1`，不应直接暴露到公网。自建服务器使用独立登录校验及 HTTPS，未登录不能调用测评 API。
- 14 项种子测试不是银行认证、监管结论、信用评级或真实事故概率。
- 自动测试使用受控协议替身，不等于真实服务商联调。首次真实调用需用你的有效 Key 完成连接和三任务试跑。
